# ScreenGuardian - 儿童电脑使用时间管理工具

## 📝 项目简介

ScreenGuardian 是一款专为家长设计的儿童电脑使用时间管理工具。它可以帮助家长控制孩子的电脑使用时间，促进健康的用眼习惯。

## ✨ 主要功能

- **时间管理**: 设置连续使用电脑的时长和休息时长
- **强制休息**: 到达设定时间后自动锁定屏幕，强制进入休息模式
- **友好提示**: 休息期间显示眼保健操和健康建议
- **家长控制**: 密码保护的设置界面，防止儿童随意修改
- **系统托盘**: 后台运行，通过托盘图标显示状态
- **防绕过机制**: 基本的防关闭保护，防止儿童强制结束程序

## 🔧 系统要求

- Windows 7/8/10/11
- Python 3.7 或更高版本
- 建议内存：2GB 以上

## 📦 安装说明

### 方法一：快速启动（推荐）

1. 下载所有文件到一个文件夹
2. 双击 `start.bat` 文件即可启动
3. 首次运行会自动安装依赖包

### 方法二：手动安装

1. 确保已安装 Python 3.7+
2. 打开命令行，进入程序目录
3. 安装依赖：`pip install -r requirements.txt`
4. 启动程序：`python screen_guardian.py`

## 🚀 使用教程

### 首次运行设置

1. **启动程序**：双击 `start.bat` 或运行 `python screen_guardian.py`
2. **设置密码**：首次运行会提示设置家长控制密码（建议4位以上）
3. **配置时间**：设置工作时长和休息时长
   - 工作时长：推荐 30-60 分钟
   - 休息时长：推荐 10-20 分钟

### 日常使用

1. **后台运行**：程序启动后自动最小化到系统托盘
2. **查看状态**：右键托盘图标可查看当前状态
3. **修改设置**：右键托盘图标 → 设置 → 输入密码
4. **暂停监控**：临时需要时可通过托盘菜单暂停监控

### 托盘图标状态说明

- 🟢 **绿色**：正常工作状态
- 🟠 **橙色**：警告状态（剩余5分钟）或已暂停
- 🔴 **红色**：休息状态

## ⚙️ 配置说明

程序会自动创建 `screen_guardian_config.json` 配置文件，包含：

```json
{
  "work_duration": 45,      // 工作时长（分钟）
  "break_duration": 15,     // 休息时长（分钟）
  "password_hash": "...",   // 密码哈希值
  "first_run": false        // 是否首次运行
}
```

## 🛡️ 安全特性

1. **密码保护**：SHA256加密存储，防止密码泄露
2. **单实例运行**：防止多次启动造成冲突
3. **防关闭保护**：禁用常见的窗口关闭操作
4. **进程锁定**：文件锁机制防止重复运行

## 🔧 常见问题

### Q: 程序无法启动？
A: 检查是否已安装 Python 3.7+，运行 `start.bat` 会自动检查并提示

### Q: 托盘图标不显示？
A: 检查系统托盘设置，确保允许显示所有图标

### Q: 忘记密码怎么办？
A: 删除 `screen_guardian_config.json` 文件，重新启动程序可重新设置

### Q: 如何完全卸载？
A: 删除整个程序文件夹即可，程序不会在系统中留下其他文件

### Q: 孩子强制关机怎么办？
A: 程序在重启后会自动恢复运行，建议将 `start.bat` 加入开机启动项

## 🚨 注意事项

1. **首次使用**：建议先测试较短的时间设置，确保程序正常工作
2. **密码安全**：请妥善保管家长控制密码
3. **定期检查**：建议定期检查程序是否正常运行
4. **备份配置**：重要的配置可以备份 `screen_guardian_config.json` 文件

## 🌟 开机自启动设置

### Windows 方法：

1. **任务计划程序方法**（推荐）：
   - 打开"任务计划程序"
   - 创建基本任务
   - 设置程序路径为 `start.bat` 的完整路径
   - 设置为"用户登录时"启动

2. **启动文件夹方法**：
   - 按 `Win + R` 打开运行对话框
   - 输入 `shell:startup` 并回车
   - 将 `start.bat` 的快捷方式复制到该文件夹
